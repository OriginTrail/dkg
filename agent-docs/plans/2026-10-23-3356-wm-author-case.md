## Executive summary

Named WM reads reconstruct a case-sensitive lifecycle URN from the supplied EVM
address. A miss loses the allocated KA number and falls back to an empty legacy
name-keyed graph. Resolve the persisted author spelling for public WM reads,
using an exact graph/name/subgraph scope and EVM identity comparison. Preserve
historical subjects and fail explicitly on ambiguous or unavailable evidence.
Keep mutation identity, signatures, authentication and private graph access intact.

## Evidence and design

- [Issue 3356](https://github.com/OriginTrail/dkg/issues/3356) reports checksum
  versus lowercase reads differing after SWM pull/restart on Blazegraph.
- `knowledge-assets.ts` validates explicit addresses and forwards the selected lane
  through `DKGAgent.assertion.query` to `DKGPublisher.assertionQuery`.
- `wmGraphUri` reads `assertionLifecycleUri` by exact subject. That constructor and
  `contextGraphAssertionUri` intentionally preserve historical spelling;
  `contextGraphLayerUri` normalizes numbered graph addresses.
- Existing `assertionLifecycleAuthorCandidates` enumerates caller/checksum/lowercase
  for repair. That is insufficient to discover arbitrary historical mixed casing.
- Resolve only the public read path rather than changing shared URI constructors
  or mutation helpers. Global normalization would strand existing subjects and
  alter seal identity; broad mutation normalization exceeds this issue's scope.
- Discover stored lifecycle candidates using bound metadata predicates in the exact
  meta graph and exact name/scope. Compare only the address segment without case;
  do not lowercase graph IDs or KA names. Validate returned evidence and reject
  multiple candidate subjects rather than choosing by request spelling/order.
- For a lifecycle-free legacy draft, preserve the existing exact graph fallback.
  Do not silently treat malformed query results as absence.

Before: request spelling -> exact lifecycle miss -> legacy graph -> false empty.
After: equivalent EVM identity -> stored lifecycle spelling -> existing WM graph.
