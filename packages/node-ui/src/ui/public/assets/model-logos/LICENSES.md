# Model-family logo assets

The five brand SVGs in this directory (qwen, openai, deepseek, meta, mistral)
are bundled from [lobehub/lobe-icons](https://github.com/lobehub/lobe-icons)
(`packages/static-svg/icons/`), MIT-licensed (LICENSE reproduced below as
LICENSE-lobe-icons). Model and brand names are used nominatively to identify
the model families being offered; no endorsement is implied. Assets are
served locally only — never hotlinked (CLAUDE.md rule 8). Unknown families
render the generated `.logo-monogram` fallback.
